# ORACLE

Ephemeral Ghost ingress, local claims, signatures, and evidence identity.

This is an independent Ground Zero Gaming server-card port:

- repository: `rustycohl/ORACLE`
- Page: https://rustycohl.github.io/ORACLE/
- flag: `DEDICATED_REPO_PAGE`
- status: `alpha`
- dependencies: none at runtime

The alpha uses an in-memory Ed25519 development session, not a JOKE wallet.

## Verify

```text
npm test
```

The Page runs the same browser-compatible self-test. It has no external
runtime dependency and does not introduce game-server authority.
